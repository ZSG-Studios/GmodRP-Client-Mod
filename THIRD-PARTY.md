The installer redistributes the official x64 DXVK 3.1.1 D3D9 binary under
[its upstream license](third_party/dxvk/LICENSE). Its release archive is pinned
to SHA-256 `40565b4a724aadc4433fa4e010b4b23916d9b1f1baeee64e17186db94f54e608`.

The menu module uses Garry's Mod Common headers and MinHook. Their complete
license notices are retained in `third_party/garrysmod_common/LICENSE.txt`
and `third_party/minhook/LICENSE.txt` and included with binary packages.

Valve game binaries, CSS content, server data and credentials are not part of
this project.
